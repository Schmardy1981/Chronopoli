Chronopoli - Clickable Demo
===========================

1. Unzip, keep the folder together.
2. Double-click index.html (opens in any current web browser). No internet needed.
3. Press "Start the tour", then click through the windows like a real product.

Navigator at the bottom: Prev / Next, window n of 58, menu path and title, who is signed in, Map.
Keyboard: left / right arrow = previous / next window, M = map, H = highlight what you can click,
F = fit windows to the browser width (on by default), Esc = close the map.
AI Tutor: open the gold button at the bottom right, type a question, press Enter.

Illustrative demo data · not a live platform · Tether shown as an illustrative demo partner, no partnership implied.
