Buffer design
Two-tranche buffers
Network A432k
Network B288k
Shared180k
Operating tranches: 60 / 40 split of the 720k peak windowReserve = 0.25 × 720k

Operating tranche

Pre-funded on each network for its share of the peak window.

Shared reserve

Moves to whichever network is congested, within one rebalancing cycle.

Rule of thumb
1.25×
Congestion multiplier on the peak window
Apply it to the network with the slowest finality. Review it monthly against missed or late payouts.

Start with Thursday: 1.8 million leaves across the day, but 720k of it goes between ten and one. That three-hour window is what the buffer has to survive before the next rebalance, so size for it and not for the daily total. Ask the room where their own peak sits, then move to the two-tranche split on the next slide.
